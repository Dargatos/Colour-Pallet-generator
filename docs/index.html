Help / Info

Colours (sidebar) is the main tool: build palettes by adding colours, preview the resulting square image, and save your colourset.

  • Add / Remove / Edit — manage colours in each palette (click a colour to select it).
  • Gradient — interpolate between your palette colours; set how many steps.
  • Shuffle palettes — combine multiple palettes into one interleaved output.
  • Create — name it and download a .txt colourset file (SoundSpacePlus format: one hex per line).
  • Keyboard: press ? for the hotkey cheat sheet · ← / → switch palettes · Alt+↑/↓ move colour · A add · D delete · R random · G gradient · M shuffle · S save
  • Tip: drag swatches to reorder — the others glow in the dragged colour · everything is saved in your browser automatically.
